# 项目名称

一两句话说明这个项目做什么、给谁用。

## 快速开始

环境要求：Node.js 20+ / Python 3.11+（按实际填写）

```bash
npm install
npm run dev
```

## 常用命令

| 命令 | 作用 |
|---|---|
| `npm run dev` | 本地开发 |
| `npm run build` | 构建，输出到 `build/` |
| `npm test` | 运行测试 |

## 目录结构

```
.
├── src/        # 源码
├── public/     # 静态资源
├── scripts/    # 开发与构建脚本
├── docs/       # 文档
└── out/        # 生成物（已忽略，由 npm run build 生成）
```
